# Bharathkumar M — Futuristic Dark Developer Portfolio 🚀

Welcome to the personal portfolio website for **Bharathkumar M**, a second-year college student at KG College of Arts and Science and aspiring developer.

This website is styled with a **futuristic dark developer aesthetic**:
- **Palette:** Deep void black and dark navy (`#05070f`, `#0d1527`) with electric-blue (`#2563eb`) and cyber-cyan accents (`#00f2fe`, `#38bdf8`).
- **Profile Photo:** Real portrait photo framed in a rounded cybernetic card (`border-radius: 28px`) with subtle glowing rings, keeping the full head of hair, face, and blazer/upper body visible without clipping.
- **Glassmorphism:** Translucent glass cards with backdrop-filter blur, interactive mouse spotlight sheen, and glowing borders.
- **Background:** Lightweight 60fps HTML5 canvas cyber particles connecting with dynamic faint cyan nodes.
